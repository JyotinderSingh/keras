# Card: RTX 4090 secure $0.89/h (community $0.34 when it has stock). The
# sm_89 rows target the RTX 4090 (the Mosaic GPU rows take its 128 SMs),
# so no other card.
# Budget 1.6 h (the old S1 1.5 h; S5 merged in). Session deadline 144 min.
# Margin cost at the secure price: 1.5 x 1.6 h x ($0.89 + $0.011 for the
# 80 GB disk) = $2.16.
# Times from the create (pod_env.py): KSTART_BY 15 min, KSTAGES_UNTIL 129
# min, KHARD_UNTIL 134 min.
# Expected stage times (normal host / slow host as V1 and V2a): the env
# checks 0.3 min; the kernel checks 9 / 19 min (V2a: 1135 s); rows-triton
# 8 / 12 + 4 / 6 + 4 / 6 min; rows-mosaic 10 / 16 + 5 / 8 + 5 / 8 min;
# the N5 stages 8 / 12 + 3 / 5 + 7 / 11 min; nsys 6 / 8 min. In total
# about 75 / 115 min. The stage minutes add up to more than
# global_timeout, so on a slow host the stage deadline cuts the last
# stages first: nsys, then the TF N5 rows.
#
# Rows (rows.py; the rule of each route is in its docstring and in
# SESSION.md section 8). Each `rows-*` stage prints one KPROF verdict per
# row: (backend, device class, dtype, M bucket) -> pass, complete, the
# worst cells. Method: stream timing (calls back to back, one sync). On
# torch the reference path does not capture in a CUDA graph (per-call host
# copies in packing.py), so every torch row compares eager stream times;
# the graph time of the route is recorded and decides nothing. M per
# bucket: 1 and 16 (1-16), 64 (17-64), 256 (65-256), 2048 (257+).
# - rows-triton-decode, rows-triton-prefill: _ALLOW_LIST (torch,
#   cuda-sm89, {bfloat16, float16, float32}, every bucket), route triton
#   (<= 0.95 x min(F0, N5)) and n5 (<= 0.90 x F0). gptq_act reports the
#   general path against F0 and decides nothing.
# - rows-triton-logits: _LOOKUP_ALLOW_LIST (torch, cuda-sm89, {bfloat16,
#   float16, float32}, {1-16, 17-64}), route triton (<= 0.90 x F0 at 1-16,
#   0.95 x at 17-64), the five tables of plan 4.4.1.
# - rows-mosaic-decode, rows-mosaic-prefill: _ALLOW_LIST (jax, cuda-sm89,
#   {bfloat16, float16}, every bucket), route mosaic_gpu (<= 0.90 x
#   min(F0, F1, F3) at 1-16, 0.95 x elsewhere), and n5 on JAX 0.12.0.
# - rows-mosaic-logits: _LOOKUP_ALLOW_LIST (jax, cuda-sm89, {bfloat16,
#   float16}, {1-16, 17-64}), route mosaic_gpu.
# - rows-n5-jax-ci: n5 on JAX 0.10.2 (jax, cuda-sm89, {bfloat16, float16,
#   float32}, every bucket). A JAX row carries n5 only where it passes on
#   both JAX venvs (the key holds no version).
# - rows-n5-jax-new-f32: n5 on JAX 0.12.0 in float32 (Mosaic GPU has no
#   float32 form).
# - rows-n5-tf: (tensorflow, gpu, {bfloat16, float16, float32}, every
#   bucket). The TF device class is "gpu" for every card, so a TF row
#   needs a pass on sm_89 (S1), sm_90 (S3) and sm_86 (S4).
# - nsys-triton, nsys-mosaic: the device time per layer (chain_split.py
#   report) of the reference, N5 or F3, and the kernel at int4 g128
#   4096x4096, M 1 and 2048: the check that a stream time measures the
#   GPU. They decide nothing.
# Format: SESSION.md, "Session files". Stage order is priority order. Not
# a loop session.

# timed call, so chain_split.py report finds one burst per call. ---
check prof-nsys nsys torch gpu 5 $PROF probe --install --require nsys
prof nsys-triton triton+nsys torch gpu 6 NSYS=$(python -c "from benchmarks.quantized_matmul.pod.prof import find_tool; print(find_tool('nsys'))"); rc=0; for run in F0:1 n5:1 triton:1 F0:2048 n5:2048 triton:2048; do IFS=: read -r cand m <<< "$run"; t="$KSTAGE_OUT/int4_g128-4096x4096-m$m-$cand"; echo "$(date -u +%H:%M:%S) run $run"; "$NSYS" profile --trace=cuda --sample=none --cpuctxsw=none --cuda-graph-trace=node --force-overwrite=true -o "$t" python -m benchmarks.quantized_matmul.pod.rows run --route=triton --candidates=$cand --gap_ms=2 --modes=int4_g128 --dtypes=bfloat16 --shapes=4096x4096 --m=$m --warmup=3 --calls=20 --l2_mb=$KL2_MB --out="$t.jsonl" > "$t.log" 2>&1 && "$NSYS" export --type=sqlite --force-overwrite=true -o "$t.sqlite" "$t.nsys-rep" > /dev/null 2>&1 && python benchmarks/quantized_matmul/pod/chain_split.py report "$t.sqlite" --meta="$t.jsonl" --calls=20 > "$t.split.json" || { echo "run $run failed"; rc=1; }; rm -f "$t.nsys-rep" "$t.sqlite"; done; bash -c 'exit $0' $rc
