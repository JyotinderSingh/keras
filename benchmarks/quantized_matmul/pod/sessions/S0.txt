# S0: smoke session, sm_89 (plan_v3.md 8.4 and 4.3).
# Cards: RTX 2000 Ada secure $0.24; L4 secure $0.59; RTX 4090 community $0.34.
# Budget 0.5 h. Session deadline 45 min (1.5 x budget).
# Times from the create (pod_env.py): restart probe 5 min, KSTART_BY 20 min,
# KSTAGES_UNTIL 30 min, KHARD_UNTIL 35 min.
# Worst case: pull and probe 5 + install 12.5 + stages to KSTAGES_UNTIL (30)
# + chunks 1 + grace 5 = KDONE at 31 min, the grace ends at 36 min. The
# watchdog can stop the pod at 35 min, 1 min before the grace ends.
# Format: SESSION.md, "Session files". Stage order is priority order.
#
# S0 items outside this file:
# - Image contents, versions, nvidia-smi: the KPROBE lines.
# - Install time of each venv: the KINSTALL lines.
# - The size cap of stream-pod-logs: the KFILL lines (logcap_kb).
# - The read rate of the chunks, and if stream-pod-logs reads an EXITED pod.
# - Restart behavior after an exit: env KRESTART_PROBE_UNTIL (SESSION.md).
# - The self-stop with the pod-scoped key: after KDONE and the grace time.
session S0
venvs jax-ci jax-new jax-floor torch tf
install_timeout 12
global_timeout 22
deadline 45
grace_s 300
restart_probe_s 300
