# O2: sm_89, optimization of Mosaic GPU K1 and Mosaic GPU K-packed
# (plan_v3.md 8.9).
# Cards: RTX 4090 community $0.34; L4 secure $0.59; RTX 4090 secure $0.89.
# Budget 1.5 h. Session deadline 135 min (1.5 x budget).
# Times from the create (pod_env.py): KSTART_BY 15 min, KSTAGES_UNTIL 120 min,
# KHARD_UNTIL 125 min. pod_env.py also sets KQUEUE_BRANCH to
# kernel-pod-queue-<RUN_ID>, the default branch of push_job.sh. The first
# push to the pod needs --create (PARALLEL.md).
# Loop mode (SESSION.md section 10). The stages of this file are job 0: they
# run once after the setup, on the measurement commit of the create. Then
# the pod runs each job that Claude pushes with push_job.sh, and stops 15
# min after the end of the last job (idle_stop_s), or at KHARD_UNTIL.
# global_timeout is the stage window of job 0 and the default timeout of
# each later job: give push_job.sh a timeout for the later jobs. Job 0 has
# about 8 min of checks and 15 min of timing and profiling (50 min at most),
# so the loop jobs get most of the budget. The configuration sweep of
# Mosaic GPU K1 (tune.py) is the session T2 (SESSION.md section 8); a loop job
# can run one sweep stage of T2.txt again after a kernel change.
# Goal (plan 8.9): Mosaic GPU K1 decode at 50% or more of the copy bandwidth
# at K = N >= 4096; Mosaic GPU K-packed past the K-packed row rule against
# F0 (plan 8.3). Claude deletes the pod when the goal is met, when two jobs
# in sequence gain less than 3%, or at the budget. If the Mosaic GPU stop
# rule of plan 8.3 applied after S1, O2 does not run.
# Content of later jobs (plan 8.9): BNH, stages, SPLIT_K, min_blocks, BM,
# the cost of the `rows` frontend.
# Format: SESSION.md, "Session files". Stage order is priority order.

# ncu on one launch of the kernel. The Pallas kernel `kernel` of
# `_w4a16_kernel` lowers to the host function `kernel_mosaic_gpu` (the
# exported module, JAX 0.12.0), so the regex takes the names with
# `mosaic_gpu`. The jax-profile stage above lists the device kernel name;
# if ncu finds no metric rows, set the regex to that name. The graph timing
# of the cell launches the kernel 8 times (2 warm-up calls, 5 timed calls,
# 1 call for err); ncu measures the fifth.
prof ncu-k1 mosaic+ncu jax-new gpu 8 $PROF ncu --kernel regex:mosaic_gpu --launch-skip 4 -- --levels=dense --modes=int4_g128 --shapes=4096x4096 --m=1 --forms=F0 --routes=mosaic_gpu --timing=graph --warmup=2 --calls=5 --copy_mb=64 --l2_mb=$KL2_MB
