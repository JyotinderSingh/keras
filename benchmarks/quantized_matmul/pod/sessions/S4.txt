# S4: sm_86 (A40), the sm_86 allow-list rows of P8b and P12b and the
# shared-memory fit rule on a card with 99 KB per block (plan_v3.md 4.1,
# 4.3, 8.3, 8.4 and 9; SESSION.md section 8, the row sessions). The first
# run of both kernels on sm_86. sm_86 has no tuned rows: Triton takes its
# default rows, fitted to the shared memory of the device (`fit_config`),
# and Mosaic GPU takes the start rows of MOSAIC_GPU_CONFIGS for 84 SMs.
# Measurement commit: as S1 (fork branch kbench-rows).
# Cards: A40 secure $0.59/h (48 GB, 84 SMs: the SM count of _SMS for
# 8.6). Fallbacks with less memory and other SM counts change the Mosaic
# GPU split: RTX A6000 secure $0.59 (84 SMs), RTX 3090 $0.22-0.50 (82
# SMs). No RTX 3070 (8 GB).
# Budget 1.2 h (SESSION.md section 8: 0.75 h; the rows of two kernels on a
# card with no tuned rows need the stages of S1 at a smaller grid).
# Session deadline 108 min. Margin cost at the secure price: 1.5 x 1.2 h
# x ($0.59 + $0.011) = $1.08.
# Times from the create (pod_env.py): KSTART_BY 15 min, KSTAGES_UNTIL 93
# min, KHARD_UNTIL 98 min.
# Expected stage times (normal host / slow host): the kernel checks 8 /
# 15 min; the fit stages 3 / 5 min; rows-triton 4 / 6 + 4 / 6 + 4 / 6
# min; rows-mosaic 7 / 11 + 4 / 6 + 4 / 6 min; the N5 stages 5 / 8 + 2 /
# 3 + 5 / 8 min. In total about 50 / 80 min. The stage deadline cuts the
# last stages first: the TF N5 rows.
#
# The fit rule (plan 4.1, 4.3): `triton-fit` lists each compiled Triton
# kernel of the default rows at M 1, 64, 256 and 2048 in three dtypes,
# with its shared memory (`shared`, KPROF lines; the limit is 101376
# bytes); `mosaic-fit` gives the SMEM of each Mosaic GPU kernel from
# ptxas. The triton-k1 module also holds the compile test of the rows
# for sm_86 (`test_compiles_for_cuda`).
# Rows (rows.py; stream timing, as in S1.txt). M per bucket: 1 and 16
# (1-16), 64 (17-64), 256 (65-256), 2048 (257+).
# - rows-triton-*: _ALLOW_LIST and _LOOKUP_ALLOW_LIST (torch, cuda-sm86,
#   {bfloat16, float16, float32}, ...), routes triton and n5.
# - rows-mosaic-*: _ALLOW_LIST (jax, cuda-sm86, {bfloat16, float16},
#   every bucket) and _LOOKUP_ALLOW_LIST (..., {1-16, 17-64}), route
#   mosaic_gpu, and n5 on JAX 0.12.0.
# - rows-n5-*: n5 on JAX 0.10.2, JAX 0.12.0 in float32, and TF eager
#   (a TF row needs S1, S3 and S4).
# Format: SESSION.md, "Session files". Stage order is priority order. Not
# a loop session.
session S4
venvs jax-ci jax-new torch tf

global_timeout 85
deadline 108
grace_s 300
# The L2 of the A40 (6 MB): every chain has the least 8 layers.
