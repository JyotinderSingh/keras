# --- The existing tests under "require" (Q4, V2a only), as one stage:
# the torch files in the torch venv in the background, and the same files
# in the jax-new venv in the foreground. The two suites share the GPU
# (JAX without preallocation) and run in about the time of the JAX suite
# alone. The two torch op modules run in triton-k1 and triton-logits

# The two JAX deselects import TensorFlow (the jax-new venv has none).
# junit-torch.xml and junit-jax.xml hold the results; failures.json gets
# the totals and each failure and error of both suites with its message;
# torch.log is the torch output. The route `require` gates no stage. The
