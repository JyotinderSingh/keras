# S1r: sm_89 (RTX 4090), the existing tests under "require" for P8b and
# P12b (plan_v3.md 7.4 and 9: G1-G8 under "require" on the pods). It runs
# at the same time as S1, on its own pod, so the suites do not disturb the
# timing of S1.
# Measurement commit: as S1 (fork branch kbench-rows).
# Card: RTX 4090 secure $0.89/h; RTX 4090 community $0.34; L4 secure $0.59
# (the suites check correctness only, and every sm_89 card runs the same
# table rows of the kernels).
# Budget 1.2 h. Session deadline 108 min. Margin cost at the secure price:
# 1.5 x 1.2 h x ($0.89 + $0.011) = $1.62.
# Times from the create (pod_env.py): KSTART_BY 15 min, KSTAGES_UNTIL 93
# min, KHARD_UNTIL 98 min.
# The files: those of the require step of .github/workflows/gpu_tests.yml
# without the two torch op modules (S1 runs them under "require" in
# triton-k1 and triton-logits).
# - torch: one stage. V2a: 2004 passed, 117 skipped in 909 s on a slow
#   host; T1b 817 s.
# - JAX 0.12.0: 2118 tests. V2a ran them in one stage of 45 min beside the
#   torch suite and stopped at 76%; T2b ran them alone in 1365 s on a
#   normal host. Here they run in five parts of about 424 tests: the shard
#   plugin of this folder (shard.py, KSHARD=<part>/5) gives test i to part
#   i % 5 + 1, so each part holds a fifth of each file. Expected 5 min per
#   part on a normal host and at most about 11 min on a slow host; the
#   limit is 15 min each. The two deselected tests import TensorFlow (the
#   jax-new venv has none).
# Each stage writes junit.xml, then failures.json (the totals, and each
# failure and error with its message). The routes require-torch and
# require-jax gate no stage. The stage status is the exit code of pytest.
# Expected: 15 + 5 x 11 = 70 min on a slow host, 14 + 5 x 5 = 39 min on a
# normal host.
# Format: SESSION.md, "Session files". Not a loop session.
session S1r

deadline 108
grace_s 300
l2_mb 72
